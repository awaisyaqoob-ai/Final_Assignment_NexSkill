## Setup

Install Python 3.12 or a compatible version, then install the packages used by the specific exercise. Common dependencies include:

```bash
python -m pip install numpy pandas matplotlib seaborn scikit-learn tensorflow selenium beautifulsoup4 requests xgboost lightgbm
```

The diamond project may require additional packages, including `pytorch-tabnet`, depending on the models enabled. Some scripts require Chrome and a matching Selenium browser driver. Run scripts from their containing directory when they reference local CSV files.

## Notes

- Files are organized as learning exercises; individual scripts may require additional dependencies.
- CSV datasets are provided in the folders where the exercises expect them.
- Model training is dataset and environment dependent; results are not guaranteed to match across machines.
