## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/awaisyaqoob-ai/Final_Assignment.git
```

**2. Navigate to the project**

```bash
cd Final_Assignment
```

**3. Install required libraries**

```bash
python -m pip install numpy pandas matplotlib seaborn scikit-learn tensorflow selenium beautifulsoup4 requests xgboost lightgbm
```

**4. Install additional packages if needed**

```bash
python -m pip install pytorch-tabnet
```

**5. Run a Python project**

```bash
python "Deep Learning/ANN/classification.py"
```

**Note:** Some scripts require additional dependencies, local CSV datasets, or a compatible Chrome browser for Selenium.
